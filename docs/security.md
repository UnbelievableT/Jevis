# 执行与数据边界

## 当前可验证的边界

- daemon 固定绑定 127.0.0.1，默认生成 32 字节随机令牌并以 0600 写入本地文件。
- Host 限于 localhost/127.0.0.1；Origin 为明确的本地工作台、移动预览和 Tauri 来源。
- 浏览器只持有本地控制令牌，不持有模型 API key。令牌存在 sessionStorage，不写 localStorage 或 URL。
- POST 校验内容类型、大小、Schema、幂等键和任务修订。
- Jev 云端适配器需要显式许可，日志关闭，默认不重试。真实编码执行器、工具执行和沙箱尚未接入；未配置实现明确抛错。
- Tauri renderer 未启用 shell、文件系统或网络任意访问插件。
- 未知副作用不能自动重试；路径预检会解析现有目标的符号链接。
- 源码与数据中的文本只作为数据，不成为策略授权。

路径预检不是内核沙箱，存在 TOCTOU 风险，不能据此启用主机工具执行。演示不调用工具，也不改变用户仓库。

## 完整产品必须实现的边界

系统凭据库、模型通道许可与认证、实际平台沙箱、工具权限、动作前审批、操作回执与对账、工作区租约、fencing、敏感产物访问、日志分类脱敏、可信 TLS 配对、设备撤销与备份恢复。

授权应绑定具体动作、规格/产物摘要、有效期和设备，不能批准后更换参数。远端不可逆动作发生超时，应进入 unknown 等待对账，而不是再执行一次。重启恢复不宣称全局 exactly once。

## 数据策略

源代码、原始证据、上下文和经验默认本地。云端 Judge 也是云端出口；local-only 项目不能把代码交给 Jev 云接口。使用量需要区分实际账单、估计费用、订阅池额度和不可观测值。

错误响应不泄露内部异常。telemetry/redact 只处理敏感字段名，无法识别所有散落在字符串中的秘密，所以默认禁止记录原始 prompt 和 provider payload。

## 当前限制

本地令牌不是多用户系统，不能用于公开服务。还未实现配对、令牌轮换 UI、速率控制、数据库加密、生产审计归档或安全发布。限制在状态表中保留，直到真实实现与测试完成。
