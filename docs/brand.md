# Jevis 品牌与视觉

产品：Jevis。域名：Jevis.xyz。英文短句：**Many minds. One direction.**  
中文：**把模型，组织成团队。**

## 已生成的素材

| 文件                              | 用途                                                           |
| --------------------------------- | -------------------------------------------------------------- |
| assets/brand/logo.png             | 正式使用的森林绿底 J 标志，官网、工作台、favicon、原生图标输入 |
| assets/brand/logo-transparent.png | 首次生成的透明标志探索稿，保留来源，不作为默认 UI 资产         |
| assets/brand/hero.png             | 保留的协作结构品牌主视觉；新版极简官网不展示                   |
| assets/brand/empty-state.png      | 软件空状态/新工作流引导                                        |
| assets/brand/prompts.json         | 完整生成提示词、工具与源文件记录                               |
| apps/desktop/src-tauri/icons/     | 由 Tauri icon 工具生成的平台派生图标，可重新生成               |

全部品牌 Logo 和插画通过内置图片生成模型创作，并已复制到本项目；未使用图库或外部品牌 Logo。Lucide 仅用于通用功能图标。网页文字是可访问的 HTML，而不是烘焙进图片。

图片源为生成的 PNG 位图，没有伪造可编辑 SVG。后续如要印刷或商标规范，应专门制作几何一致的矢量版本，并另行核查品牌可注册性；本次不声称已完成注册或独占性检索。

## 视觉规则

- 官网采用黑白与暖灰、留白和文字层级；森林绿只保留在 Logo。工作台沿用森林绿交互色；官网不再使用大幅装饰性插画。
- 英文字体 Manrope Variable，通过本地 npm 字体资源加载；中文使用系统字体回退。
- 保留标志四周空白，避免把 J 图形用作完成/安全认证标志。
- 插画用于解释协作理念，不代表真实任务成果或性能数据。
- 默认克制动效，遵守 prefers-reduced-motion。
- 用真实状态文案表达未接入、暂停、验证和失败，不靠颜色单独传达状态。
